## Perubahan

`evaluator/text_context.py` menyiapkan A/B dari report dan aturan publik yang sama, dengan projection fakta B dari evidence tersimpan. Role admin/owner membership, report/revision/body, scope/epoch, snapshot/boot, envelope, journal, provenance dan hash file diperiksa. Source jawaban, GT/kondisi, assessment/verdict, catatan admin, raw HTML/DOM/screenshot dan filename aktif tidak masuk payload. Projection tidak menjalankan target atau verifier; kecukupan bukti tetap perlu review. Status/kontrol negatif tidak diubah menjadi label otomatis.

Adapter OpenRouter menerima kontrak prompt/schema teks opsional, dengan default triage R1 dipertahankan. Prediksi evaluasi memakai schema VALID/INVALID/ABSTAIN dan referensi allowlist. `text_dispatch.py` menyimpan request terikat, seluruh attempt/raw tereduksi/error/usage/biaya pada DB aplikasi, tanpa run lab baru. Migrasi **006** menambah evaluation_jobs dan binding eksklusif run/triage/evaluation pada ledger/attempt, menyalin semua data lama. Ledger lama tetap otoritatif; tidak ada budget baru untuk evaluator. Satu attempt/slot, tanpa fallback/retry. Revocation/timeout/cancel mempertahankan biaya unknown; overcost memerlukan rekonsiliasi. Pemulihan eksplisit tidak me-replay request.

`text_benchmark.py` menyediakan contexts/smoke/freeze/run/export/recover dan simulasi offline. Freeze memeriksa review GT/kuota, binding konteks, batas token, smoke development dengan usage/cost diketahui pada source/kontrak/profil sama, serta sisa budget konservatif untuk seluruh jadwal. Source/prompt/schema/model/provider/harga/limit/urutan dikunci; perubahan ditolak. Rekaman error/abstain/NOT_STARTED tetap dalam scorer. Output database tetap sumber attempt; ekspor privat tidak mengubah assessment.

Compose menambahkan env_file app dan profil evaluator opsional yang memakai volume app_data yang sama. Key tidak dikirim ke worker/lab; image produk app/worker/lab tidak memuat evaluator. Image evaluator khusus operator memuat source yang diperlukan. Service aktif tidak di-rebuild/restart; schema aktif lama tetap dipertahankan. Penerapan schema006 ke app aktif menunggu operasi update yang disetujui pengguna; tes migrasi hanya pada data disposable.

R3c menyiapkan `artifacts/r3/review-v1/`: proposal PROPOSED_NOT_GT, binding template null, panduan per kandidat, jadwal40 NOT_STARTED dan report pending metrik null. Kandidat/CSV/manifest R3a tidak diubah. Tidak ada bukti terikat yang dikarang atau GT otomatis. Pemeriksaan konfigurasi sekali menghasilkan CONFIGURATION_REQUIRED: seluruh key/profil/tier/harga/kurs/token bound/reservasi live belum terisi; tidak ada provider request.

R4 menyediakan script source ZIP+manifest/checksum, quick start/troubleshooting, image review terpisah, slide lokal HTML/PDF, thumbnail, tiga screenshot, preview video MOCK tanpa narasi, storyboard dan draft publikasi/formulir. Lisensi asli belum dipilih; tidak membuat LICENSE sepihak. Tidak ada push, release, hosting, upload atau submit.
